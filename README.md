# Hey, I'm Hasan 👋

I build small, useful tools for questions that deserve a clearer answer. I like practical CLIs, careful data handling, and open-source projects that people can actually use.

### Things I've built

- [LocaleTripwire](https://github.com/GreedyC/LocaleTripwire) — an offline JSON checker for duplicate keys and Unicode/Turkish-casing collisions.
- [Instagram List Inspector](https://github.com/GreedyC/instagram-list-inspector) — a Codex skill for comparing Instagram lists available in your signed-in browser, with explicit coverage and privacy limits.
- [wordbreaker-m5](https://github.com/GreedyC/wordbreaker-m5) — Apple Silicon-assisted BIP39 recovery for wallets you own.
